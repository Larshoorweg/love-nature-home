# Love Nature Krabi: home page

Static home page for Love Nature Krabi Travel and Tours, a local tour operator in Krabi, Thailand. Bookings are powered by [Jai Thai](https://jaithaitravel.com).

- `index.html`: the full page (HTML, CSS and a small script, no build step)
- `assets/`: photos, hero videos (mobile and desktop) and logos
- `vercel.json`: clean URLs and long-term caching for `/assets`

Deploys to Vercel as a static site. No framework, build command or output directory needed.
